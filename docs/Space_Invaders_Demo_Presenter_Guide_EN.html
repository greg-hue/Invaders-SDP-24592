Shop controls

Up/Down selects the section; Left/Right selects a product; Space/Enter confirms; Escape returns. R retries a failed shop save. The separate economy panel has clickable actions.

Profile preparation and restart

The default rehearsal folder is .demo-profile/, separate from the normal player profile. A new rehearsal receives 1000 sample credits, ten prepared ranking entries and seven high scores. To repeat first-time unlocks, use a new folder:

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-game.ps1 -Demo -DemoProfile .\out\rehearsal-01

Reuse that exact profile path after restarting. Settings, purchases, scores, records and achievements persist. Never imply that prepared baseline entries were earned live.
