Space Invaders
Presenter Guide

48 scenes. You play the game; you choose when to move on.

Launch with JDK 17 or later

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-game.ps1 -Demo

From an IDE, run engine.Core with --demo and res on the classpath.

Presenter controls

ControlAction
Back / F6Previous scene
Restart / F7Recreate the current scene; purchases remain saved
Next / F8Continue when ready; no scene timer
F5Hold or resume prepared cues; gameplay continues
F10Exit the demo

Play normally above the footer. Use your configured movement and fire keys. Prepared items usually appear at 8 seconds; boss phase cues run at 12 and 20 seconds. Wait through the normal opening countdown.

Build note: This guide replaces the earlier pending-PR checklist. It follows final main 4007cf6. Real shop products, rewards, JSON tools, obstacles and boss effects replace the old demo adapters. Starting credits and ranking history are prepared rehearsal data.

Presenter reference

Final rules and remaining limits

AreaWhat the final version does
Ship balanceStandard: 4 lives, speed 2, 750 ms shot interval. Speedster: 3 lives, speed 4, 400 ms bursts; unlock for 200 Credits. Heavy Tank: 5 lives, speed 1, 1000 ms spread shots. Only Heavy Tank accepts shields.
Permanent upgradesHull adds up to 3 maximum lives, Engine adds up to 3 speed, Reloader reduces the interval by up to 30%. Three tiers cost 100 / 250 / 500 Credits. Effects are captured at the start of a new campaign; Endless stays unchanged.
Rewards and HUDCampaign rewards use actual enemy classifications and stage completion events. Easy / Normal / Hard clear bonuses are 50 / 100 / 200. Endless grants 1 Credit per defeat. The HUD includes pending earned Credits; purchases use the settled balance.
Bosses and soundBoss A: 850 HP; Boss B: 800 HP. Production boss selection, phases, defeat points, effects and sounds are active. Boss music plays on boss stages; the urgent last-life track has priority.
Custom levelsThe JSON reader, writer, validation and custom gameplay are implemented. Main still has no dedicated import/export menu. The demo provides a panel for a bundled example, export and revalidation. Edit presentation-level.json inside the demo profile and reload to try another definition.
ScopeThe final shop contains permanent upgrades and ships. The earlier sample consumable shop has been removed from the demo. Staged Speedster scenes preview its behavior; ordinary Hangar selection still requires the real unlock.

Persistence and rehearsal

Default saves go to .demo-profile/, separate from normal player progress. For a clean rehearsal, add -DemoProfile .\out\final-rehearsal-01 to the launch command. Reuse that path to demonstrate a restart. Back and Restart do not undo purchases.

Suggested spoken disclaimer: “This presentation runs on the final game build. The buttons and prepared encounters help us show each feature. Custom JSON tools are exposed through the demo panel because the main menu has no entry for them.”

This is a source-based integration statement, not a claim about remote PR status. No additional missing PR is assumed. The isolated profile starts with 1000 Credits and prepared high scores.
